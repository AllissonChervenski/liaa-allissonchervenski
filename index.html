Evolução completa da acurácia no NinaPro DB2 (50 classes): da linha base estática (~58%) até 68,59% ($K=5$) e 71,06% ($K=9$) com extração rica multi-domínio (M14).

Como Funciona o Pós-Processamento Temporal Causal em TinyML

Na segmentação padrão de sinais mioelétricos, usamos janelas de 200 ms com stride de 50 ms (75% de sobreposição). Isso significa que uma nova predição é gerada a cada 50 ms. Como uma contração muscular voluntária sustentada dura normalmente entre 1 e 5 segundos, de 10 a 50 decisões consecutivas pertencem necessariamente à mesma intenção motora do usuário.

A inferência estática quadro-a-quadro é suscetível a glitches — quedas momentâneas de acurácia causadas por microdeslocamento de eletrodos, ruído transitório ou fadiga. O filtro de votação majoritária causal atua como um filtro passa-baixas no domínio das decisões discretas:

ŷt = moda(ŷt, ŷt-1, …, ŷt-K+1)   [com desempate por persistência/histerese motora]
Zero Retreino Aproveita 100% dos modelos M01, M02, M07 e M11 já compilados e quantizados.
Custo Mínimo em SRAM Apenas K bytes de buffer circular FIFO na memória do ESP32-S3 (5 bytes para K=5).
< 50 Ciclos de CPU Cálculo da moda em C99 leva < 0,2 μs no ESP32-S3 a 240 MHz (impacto nulo na bateria).

Trade-off Clínico: Atraso Algorítmico vs. Estabilidade Motora em Próteses

Na literatura médica de reabilitação e controle de próteses mioelétricas superiores (Farina et al., 2014; Hudgins et al., 1993), o limiar perceptivo de latência aceitável para o usuário é de ≤ 200 ms a 300 ms. Atrasos acima de 300 ms causam sensação de descontinuidade motora ("arrasto").

$K$ Atraso Algorítmico Janela Contínua Efetiva Impacto Perceptivo Clínico Recomendação para Prótese
1 0 ms 200 ms Zero atraso, porém alto índice de flickering e trepidação em regime transitório. Não recomendado
3 100 ms 300 ms Redução sensível de transições espúrias. Praticamente imperceptível pelo usuário. Bom para alta velocidade
5 200 ms 400 ms Ponto de Equilíbrio Ótimo: Máxima estabilização de pegada dentro do limiar de 200 ms. Padrão Recomendado
7 300 ms 500 ms Pegada ultrassólida; ligeiro retardo notado apenas em sequências rápidas de troca. Adequado para pegadas fixas
9 400 ms 600 ms Ganhos de acurácia saturam; atraso ultrapassa a barreira ergonômica de 300 ms. Atraso perceptível

Código C99 para a Task do FreeRTOS (Core 1) no ESP32-S3

Implementação de zero-alocação dinâmica compatível com o firmware de classificação do Core 1: 

#define SMOOTHING_K 5

typedef struct {
    uint8_t buffer[SMOOTHING_K];
    uint8_t head;
    uint8_t count;
    uint8_t last_output;
} CausalMajorityFilter;

void filter_reset(CausalMajorityFilter *f) {
    f->head = 0;
    f->count = 0;
    f->last_output = 0;
}

uint8_t filter_step(CausalMajorityFilter *f, uint8_t raw_pred) {
    f->buffer[f->head] = raw_pred;
    f->head = (f->head + 1) % SMOOTHING_K;
    if (f->count < SMOOTHING_K) f->count++;

    // Contagem de votos na janela deslizante (50 classes)
    uint8_t freq[50] = {0};
    uint8_t max_votes = 0;
    for (uint8_t i = 0; i < f->count; i++) {
        uint8_t c = f->buffer[i];
        freq[c]++;
        if (freq[c] > max_votes) max_votes = freq[c];
    }

    // Desempate por histerese/persistência (evita vibração de motor)
    if (f->count > 1 && freq[f->last_output] == max_votes) {
        return f->last_output;
    }
    // Desempate por recência (última decisão mais recente)
    for (int8_t i = f->count - 1; i >= 0; i--) {
        uint8_t idx = (f->head - 1 - i + SMOOTHING_K) % SMOOTHING_K;
        if (freq[f->buffer[idx]] == max_votes) {
            f->last_output = f->buffer[idx];
            return f->last_output;
        }
    }
    f->last_output = raw_pred;
    return raw_pred;
}

M12: Spatial-Temporal Circular CNN-2D (Geometria em Anel + Quadrantes Azimutais)

Na CNN-1D original (M02), os 12 eletrodos são misturados indiscriminadamente na primeira camada convolucional, destruindo a topologia espacial da musculatura do antebraço. No protocolo NinaPro DB2, os 8 primeiros eletrodos formam um anel circunferencial fechado ao redor do antebraço (Ch 7 ↔ Ch 0), enquanto os eletrodos 9 a 12 são posicionados anatomicamente (FDS, EDC, Bíceps, Tríceps).

Padding Espacial Circular Envolve o eletrodo 7 sobre o eletrodo 0 antes da convolução 2D (3×9), capturando a propagação transversal de MUAPs em torno do anel muscular.
Retenção de 4 Quadrantes Em vez de colapsar todos os eletrodos num único GAP global, preserva 4 setores espaciais (flexores vs. extensores vs. radial vs. ulnar) + ramo anatômico.
BatchNorm Folding INT8 Funde Conv + BatchNorm antes da quantização Q24/INT8, mantendo queda de apenas 0,58% (FP32 → INT8) com 14.750 parâmetros (≤ 15k).

M13: Supervised Contrastive Circular CNN-2D (SupCon Balanceado + Protótipos)

No protocolo NinaPro DB2, a classe de repouso (REST) representa 36,3% de todas as janelas de treino (~28× maior que cada gesto ativo). O treinamento clássico por Cross-Entropy sofre colapso de margem entre os 49 gestos ativos e degrada sob ruído entre repetições. O M13 resolve isso no host em duas etapas e descarta a cabeça contrastiva antes de exportar para o ESP32-S3:

Stage 1: SupCon Balanceado Treina com duas vistas fisiológicas por janela ($\tau=0,10$) ponderando âncoras inversamente à frequência no lote para proteger os 49 gestos contra o domínio do REST.
Stage 2: Protótipos L2 + LDA Inicializa a cabeça linear pelos centróides L2-normalizados dos clusters contrastivos e refina ponta-a-ponta com Label Smoothing (0,05).
Queda INT8 de Apenas 0,08% Clusters contrastivos mais compactos reduzem a queda de quantização FP32 → INT8 de 0,58% para 0,08% (NinaPro 12CH), mantendo idênticos 14.750 parâmetros.

3. Fundamentação Arquitetural e Hipóteses de Projeto

O que é a arquitetura de cada modelo, por que foram escolhidos em sua forma original e por que foram combinados em arquiteturas híbridas para o benchmark.

O Princípio da Complementaridade em TinyML (Por que Unir Modelos?)

Em sistemas embarcados neuromusculares, existe o teorema "No Free Lunch": Nenhum classificador puro consegue ser simultaneamente o mais rápido, o mais preciso, o mais tolerante a variações temporais e o mais leve na bateria.

  • Modelos Lineares (Micro-LDA): Têm latência desprezível (1 µs) e quase zero consumo de RAM (200 bytes), mas sofrem com crosstalk em gestos não-lineares.
  • Redes Neurais (CNN-1D): Extraem representações morfológicas profundas e separam classes densas, mas consomem 100× mais energia e sofrem colapso sob quantizações agressivas de 8 bits.
  • Alinhamento Temporal (DTW): Absorve a variação elástica natural na cadência das contrações musculares, mas sua complexidade tradicional quadrática $\mathcal{O}(N^2)$ estoura a SRAM do microcontrolador.

A Solução Híbrida: Em vez de forçar um único modelo a resolver todo o sinal, unimos algoritmos complementares em cascatas condicionais com Early Exit, podas assintóticas restritivas e decomposição hierárquica Coarse-to-Fine, atingindo o pico de acurácia com consumo de energia mínimo.

M01: Micro-LDA Q7 Baseline Puro

O que é a Arquitetura:

Classificador linear baseado na Análise Discriminante Canônica com matriz de covariância combinada e pesos inteiros calibrados em ponto fixo Q7 ($\mathbf{y} = \mathbf{W}\mathbf{x} + \mathbf{b}$). Ocupa apenas 200 bytes de Flash e executa em menos de 284 ciclos de clock.

Por que foi escolhido originalmente:

É o padrão-ouro clássico na literatura de próteses mioelétricas. Oferece a menor latência possível (1.2 µs no ESP32-S3), garantindo resposta imperceptível e maior IRC (686.361).

Papel na Arquitetura Híbrida:

Atua como "porteiro rápido" (Gatekeeper) de primeiro nível nas cascatas M07 e M11. Quando a separabilidade do gesto é evidente (alta margem), ele resolve a predição instantaneamente sem ligar os motores neurais mais pesados.

M02: CNN-1D INT8 Baseline Puro

O que é a Arquitetura:

Rede neural convolucional temporal com 2 camadas convolucionais 1D (filtros 7 e 5), MaxPool, concatenação de features analíticas de Hudgins no gargalo e camada linear densa, quantizada simetricamente em INT8 pós-treino.

Por que foi escolhido originalmente:

Capacidade de capturar correlações espaço-temporais e micro-variações musculares sem depender exclusivamente de características projetadas manualmente, alcançando 58.62% no NinaPro DB2.

Papel na Arquitetura Híbrida:

Fornece poder de desempate de alta capacidade não-linear. Nos modelos M06, M07, M09 e M11, a CNN só é acionada nas janelas de alta ambiguidade ou refinamento fino, eliminando o desperdício de energia em movimentos simples.

M03–M05: Família DTW Assintótico Baseline de Alinhamento

O que é a Arquitetura:

Classificador 1-Nearest Neighbor baseado no Dynamic Time Warping sobre envelopes RMS. M03 é o clássico quadrático $\mathcal{O}(N^2)$, M04 restringe a janela via Sakoe-Chiba $\mathcal{O}(wN)$ e M05 aplica a cota inferior matemática LB_Keogh $\mathcal{O}(N)$ com buffer circular de 2 linhas.

Por que foi escolhido originalmente:

O sinal sEMG sofre de elasticidade temporal: usuários realizam o mesmo gesto com velocidades diferentes. O DTW alinha deformações não-lineares no eixo do tempo onde a distância Euclidiana falha.

Papel na Arquitetura Híbrida:

Graças à poda exata LB-Keogh (que descarta 95% das hipóteses sem calcular o warping completo), o DTW atua no M08 e M09 como pré-filtro ultrarrápido de templates para restringir as classes candidatas.

M06: Híbrido LDA + CNN Head Fusion Arquitetura Híbrida 1

O que é a Arquitetura:

Fusão precoce de representações: os discriminantes lineares computados pelo LDA e os mapas de ativação temporal da CNN-1D são concatenados diretamente na cabeça densa de decisão final.

Por que unir nessa abordagem:

Testar se a projeção de máxima variância entre-classes do LDA ajuda a regularizar o gradiente denso da CNN, evitando que a rede se perca em ruído de alta frequência.

Resultado no Benchmark:

Alcançou 81.79% no Ozdemir, mas mantém a latência da CNN (0.35 ms) pois exige a execução de ambos os modelos em todas as janelas.

M07: Híbrido LDA + CNN Cascade (Early Exit) Arquitetura Híbrida 2

O que é a Arquitetura:

Cascata hierárquica sequencial com saída antecipada calibrada por margem de Pareto: $\Delta_{\text{margin}} = P_{\text{top1}} - P_{\text{top2}} \ge \theta$.

Por que unir nessa abordagem:

Eliminar o custo desnecessário de inferência profunda. Se o Micro-LDA já tem alta certeza do gesto, encerra em 2 µs. Apenas quando há dúvida razoável a CNN-1D é ativada.

Resultado no Benchmark:

Atingiu o pico de acurácia de 82.69% no Ozdemir com 57.6% das janelas resolvidas no Early Exit, cortando o consumo energético em mais de 50%.

M08: Híbrido DTW + LDA (Top-M Filter) Arquitetura Híbrida 3

O que é a Arquitetura:

Filtro em duas etapas: o classificador DTW LB-Keogh elimina rapidamente as classes distantes e seleciona o subconjunto das 5 hipóteses mais prováveis ($M=5$). O LDA toma a decisão final dentro desse subespaço.

Por que unir nessa abordagem:

Reduzir a complexidade do LDA de 50 para 5 classes por janela, combinando a robustez temporal do warping com a velocidade analítica da projeção linear.

Resultado no Benchmark:

Latência extremamente baixa (0.0385 ms) com excelente acurácia de 81.32% no Ozdemir e IRC de 64.423 no NinaPro.

M09: Híbrido DTW + CNN-1D INT8 Arquitetura Híbrida 4

O que é a Arquitetura:

O DTW LB-Keogh atua como filtro restritivo de classes candidatas antes da camada convolucional, restringindo a saída densa da CNN apenas às 5 classes selecionadas.

Por que unir nessa abordagem:

Evitar a confusão do softmax em 50 saídas simultâneas, permitindo que a CNN concentre seus neurônios na discriminação fina entre gestos muito parecidos.

Resultado no Benchmark:

Atingiu a **maior acurácia bruta no NinaPro DB2 (59.73%)**, comprovando a eficácia da redução do espaço de busca antes da convolução.

M10: Tri-Híbrido DTW + LDA + CNN Arquitetura Híbrida 5

O que é a Arquitetura:

Arquitetura tripartite integrada: Tier 1 (Early Exit via LDA em 2 µs) → Tier 2 (Poda assintótica de templates via DTW LB-Keogh) → Tier 3 (Decisão neural profunda via CNN-1D).

Por que unir nessa abordagem:

Integrar todas as vantagens conhecidas na literatura: quase metade das janelas sai em microssegundos pelo LDA, e as janelas difíceis passam pelo filtro elástico do DTW antes da CNN.

Resultado no Benchmark:

Atingiu a **maior acurácia do estudo no Ozdemir et al. (82.78%)** com Early Exit de 49.2% e consumo de 0.032 mJ.

M11: Hierárquico Coarse-to-Fine (τ = 0.80) Arquitetura Proposta Principal

O que é a Arquitetura:

Desacoplamento taxonômico em dois níveis: o Macro-LDA classifica o grupo funcional em 2 µs (Repouso, Punho, Preensões Finas ou Força). Se a confiança for ≥ 80%, resolve via Sub-LDA instantâneo. Se houver dúvida ou o gesto for de preensão fina intrínseca, ativa uma CNN especialista de 23 classes.

Por que foi criada e unida:

Resolver a causa-raiz da baixa acurácia do NinaPro DB2: o crosstalk entre músculos profundos de dedos e músculos fortes de punho. Separar esses grupos no primeiro estágio permite que a CNN foque exclusivamente nas 23 pinças finas.

Resultado no Benchmark:

Empata com a CNN completa (57.96% vs 58.62%), mas com 69.0% das inferências resolvidas no Fast Path (latência de 0.099 ms e economia de 57% de energia). Sob quantização agressiva em int8, reteve 51.64% enquanto a CNN pura colapsou para 9.86%.

M12: Circular CNN-2D Espacial Passo 2 • Topologia em Anel

O que é a Arquitetura:

Rede convolucional 2D que trata os 8 eletrodos circunferenciais do antebraço como um anel fechado via circular padding (Ch 7 ↔ Ch 0), retém 4 quadrantes azimutais (flexores/extensores) e processa os 4 eletrodos anatômicos num ramo dedicado.

Por que foi criada:

Superar a mistura indiscriminada de canais da CNN-1D original, capturando propagação transversal de MUAPs ao redor do antebraço com BatchNorm folding INT8 sem custo adicional no ESP32-S3.

Resultado no Benchmark:

Com 14.750 parâmetros e 1,249 ms no ESP32-S3, atingiu 61,61% ($K=5$) e 63,42% ($K=9$) no NinaPro DB2 12CH (queda INT8 de apenas 0,58%).

M13: SupCon Circular CNN-2D Passo 3 • Custo Zero na Inferência

O que é a Arquitetura:

Treinamento em 2 estágios com Supervised Contrastive Learning balanceado por frequência inversa no lote (para conter o domínio de 36,3% do repouso) + inicialização da cabeça por centróides L2. A cabeça contrastiva é descartada antes da exportação.

Por que foi criada:

Evitar o colapso de margem entre os 49 gestos ativos na Cross-Entropy padrão e blindar a fronteira de decisão contra o ruído de quantização INT8.

Resultado no Benchmark:

Queda de quantização FP32 → INT8 reduzida para 0,08% (NinaPro 12CH) e 0,01% (2CH), atingindo 62,08% ($K=5$) e 63,57% ($K=9$) com idênticos 14.750 parâmetros do M12.

M14: 636 Features + SupCon MLP INT8 Passo 4 • Recorde Geral

O que é a Arquitetura:

Extrator multi-domínio determinístico de 636 features (TD não-linear, Hjorth, HOS, AR-4, 5 bandas espectrais, 4 cepstros EMGCC, Wavelet Haar 4 níveis, envelope em sub-janelas e 132 sinergias inter-canais) acoplado a uma MLP Residual SupCon (636 → 192 → 128 → 50 + skip LDA) em INT8.

Por que foi criada:

Substituir as 60 features Hudgins comprimidas por uma assinatura neuromuscular completa, mantendo a execução 3× mais rápida e 4× menor em SRAM que redes 2D no ESP32-S3.

Resultado no Benchmark:

Quebrou a barreira dos 70% no NinaPro DB2 (68,59% em $K=5$ e 71,06% em $K=9$, Macro F1 de 65,81%) e atingiu 80,77% no Ozdemir usando apenas 2 canais, em 0,425 ms e 7,6 KB de SRAM.

5. Matriz de Quantizações, Redução de Canais e Índices IRC / IEE

Apresentação exaustiva de todas as configurações numéricas (float32 a int8) e canais (12 a 1 canal) avaliadas em todos os modelos.

Índice de Responsividade e Capacidade (IRC)

Mede a taxa de classificação correta ponderada pelo repertório gestual por unidade de tempo no microcontrolador:

IRC = (Acurácia_Top1[%] × N_gestos) / Latência_ms
  • Significado: Quantos gestos acurados o sistema decodifica por milissegundo de CPU.
  • Objetivo: Maximizar a resposta antes do limiar perceptivo humano (< 100 ms).
  • Líder Absoluto: M01_micro_lda_q7 (IRC = 686.361 no Ozdemir e 469.671 no NinaPro).

Índice de Eficiência Embarcada (IEE)

Mede o rendimento de acurácia em relação ao custo combinado de energia e ocupação de memória SRAM em silício:

IEE = (Acurácia_Top1[%] × N_gestos) / (Energia_mJ × log10(SRAM_KB))
  • Significado: Eficiência de silício (repertório acurado por milijoule consumido e footprint de RAM).
  • Objetivo: Garantir que a prótese dure o dia inteiro sem esgotar a bateria ou exceder 512 KB de SRAM.
  • Destaque Híbrido: M11 Hierárquico atinge IEE = 140.125 (3.5× superior à CNN-1D pura).

7. Contexto do Projeto e Formulação do Problema

A fundamentação biológica, os desafios de engenharia e os três gargalos da literatura.

Contexto Clínico & Próteses Mioelétricas

Sinais de eletromiografia de superfície (sEMG) registram o potencial de ação muscular no antebraço residual de pessoas amputadas. A decodificação em tempo real desses sinais permite controlar próteses multifuncionais comerciais.

  • Janelamento Causal: Janelas de 200 ms (400 amostras a 2 kHz) com avanço de 50 ms.
  • Limiar Humano: O atraso total do sistema deve ser menor que 100 ms para que o usuário sinta controle contínuo e transparente.
  • Hardware Restrito: Microcontroladores de baixo custo (ESP32-S3) com apenas 512 KB de SRAM interna.

Os Três Gargalos da Literatura

A literatura acadêmica e a indústria de próteses enfrentam barreiras fundamentais:

  1. Teto dos 70% de Acurácia: Em bases de 50 classes como o NinaPro DB2, modelos convencionais sofrem confusão entre dezenas de gestos simultâneos.
  2. Crosstalk de Volume: Sinais de grande amplitude de flexão de punho mascaram os sinais atenuados de músculos profundos responsáveis por pinças e dedos.
  3. Inviabilidade de Redes Pesadas: CNNs 2D/3D consomem dezenas de megabytes de RAM e esgotam baterias portáteis em poucas horas.

8. Proposta de Solução Técnica

Arquitetura modular em camadas: DSP causal em streaming, features TD em ponto fixo e modelo hierárquico Coarse-to-Fine.

DSP Causal em Streaming (DF2T)

Filtro biquad IIR Butterworth de 4ª ordem (20–450 Hz) em Forma Direta II Transposta que preserva o estado de memória entre chunks do ADC sem qualquer distorção de fase.

Extrator Hudgins no Domínio do Tempo

Conjunto analítico clássico (MAV, RMS, WL, ZC, SSC) computado com banda morta de ruído de 10 µV, reduzindo a complexidade de tensores complexos para apenas 5 features por canal.

Hierarquia Coarse-to-Fine (M11)

Macro-LDA linear (τ = 0.80) que resolve ~70% das janelas no Fast Path em ~0.04 ms, ativando seletivamente a CNN-1D de 23 classes apenas quando há incerteza ou preensão fina.
